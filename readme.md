# openSUSE.Asia Summit 2026 Talk

This is my talk about "Kickstart Linux Kernel Contribution by Fixing Coverity
Issue" at openSUSE.Asia Summit 2026 that was held in Yogyakarta, Indonesia.

I am sharing how Coverity Scan report can help us getting started contributing
to linux kernel and sharing what we should consider when submitting the patch
to linux kernel mailing list.

For more information about the conference, you can check the url below:<br>
https://events.opensuse.org/conferences/oSAS26
